🚀 Sistema de Monitoramento de Disponibilidade AWS

Projeto Final - AWS re/Start | Monitoramento com Observabilidade e IA

📌 Visão Geral

Este projeto implementa um sistema de monitoramento de disponibilidade de um site, utilizando AWS CloudWatch, Alarmes, Grafana e Inteligência Artificial, com foco educacional e aplicação prática em cenários reais de mercado.

🎯 Problema que Resolve

Sistemas digitais precisam estar disponíveis 24/7. Sem monitoramento, falhas só são percebidas quando usuários reclamam. Este projeto cria alertas automáticos e inteligentes.

🔍 Observabilidade

Baseado em métricas, logs e alertas para entender o sistema em tempo real.

🧱 Arquitetura da Solução

O fluxo inclui EventBridge para agendamento, Lambda para testes, CloudWatch para métricas, IA para análise, SNS para notificações e Grafana para dashboards.

🛠️ Tecnologias Utilizadas

AWS Services

CloudWatch, Lambda, SNS, EventBridge

Grafana

Visualização de métricas em tempo real

Inteligência Artificial

Análise de padrões e alertas inteligentes
